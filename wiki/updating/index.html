Updating Graft

You move to a new version of Graft.app by hand, from GitHub Releases.

Download the new Graft.zip from GitHub Releases and replace the Graft.app in /Applications. Graft doesn't update itself.

  • Your config, apps and builds carry over, and so does your App Store sign-in.
  • The Terminal command points into the app, so it updates too.
